How I broke down the BDR problem

A BDR's real job isn't "write an email" — it's four separate research problems chained together, each with its own way to go wrong. This map shows how the pipeline splits the problem, plus the cross-cutting decisions that keep it from hallucinating or falling over mid-run.
Central problem
Automate outbound prospect research + personalized outreach — without inventing companies, people, or facts.
1

Who fits?

ICP Agent
  • Input: vertical + one reference company
  • Gemini reasons out industry, size, regions, must-haves
  • No search here — pure reasoning step
  • Returns strict schema JSON
2

Who's real?

Account Agent
  • Tavily search: industry + ref. company + region
  • Query trimmed to fit Tavily's 400-char cap
  • LLM extracts up to 5 real matches
  • Each with a "why this matches" reason
3

What's happening there?

Research Agent
  • Per-company search: initiatives, ESG, digital transformation
  • Summarized into 5 structured fact lists
  • Every item forced to plain string, never nested
4

Who do we talk to?

Contact Agent
  • site:linkedin.com/in biased search
  • LinkedIn URL only kept if it matches a real result URL
  • Model told explicitly: never guess a link
5

What do we say?

Email Agent
  • One email per verified contact, grounded in research
  • Under 150 words, personalized by role
  • Zero contacts → zero emails, on purpose
Cross-cutting: making it not fall over

LLM fallback

Gemini primary, auto-falls back to Groq if Gemini's daily quota (not just per-minute) is exhausted — checked separately so I don't waste time retrying something that won't recover for hours.

Per-company isolation

Orchestrator wraps each company's research/contacts/email in try/except. One company failing doesn't lose the accounts already found for the others.

Defensive search

A flaky Tavily call returns an empty result set instead of raising — every caller already expects an empty list, never a crash.

No fabrication, by design

Two hard rules enforced in code, not just prompted for: no invented LinkedIn URLs, no emails written against an invented persona.
